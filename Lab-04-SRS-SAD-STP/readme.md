# Lab 04: SRS, SAD, and Software Test Plan (STP)

This directory contains the foundational Software Engineering specifications for the **Digital Campus Library Reservation Gateway (LRG)**:

## Document Inventory

1. **Software Requirements Specification (SRS)**:
   - File: [`SRS_Library_Reservation_Gateway (1).pdf`](file:///Lab-04-SRS-SAD-STP/SRS_Library_Reservation_Gateway%20(1).pdf)
   - Scope: Complete functional requirements (`LRG-F-001` to `LRG-F-042`), non-functional requirements (`LRG-NF-001` to `LRG-NF-007`), security specifications (`LRG-SR-001` to `LRG-SR-007`), UML use-case diagrams, and Requirements Traceability Matrix (RTM).

2. **Software Architecture and Design Specification (SAD)**:
   - File: [`SAD_Library_Reservation_Gateway (1).pdf`](file:///Lab-04-SRS-SAD-STP/SAD_Library_Reservation_Gateway%20(1).pdf)
   - Scope: Layered modular monolith architecture, UML Component Diagram, Architectural Decision Records (ADR-1 to ADR-5), sequence diagrams (Search, Hold Placement, Title Return & Promotion), REST API interface specifications, and STRIDE security architecture.

3. **Software Test Plan (STP v2.0 - Updated for Sprints 1, 2, and 3)**:
   - File: [`Test_Plan_Library_Reservation_Gateway.docx`](file:///Lab-04-SRS-SAD-STP/Test_Plan_Library_Reservation_Gateway.docx)

   - Scope: Test strategy, levels, entry/exit criteria, updated Appendix A Test Case Catalogue (including `TC-FINE-01` to `TC-FINE-05`, `TC-HOLD-06`, `TC-NOTF-03`, `TC-SRCH-07`, and `TC-SEC-08`), and 100% accepted Requirements Traceability Matrix.

4. **Testing Deliverables (Part-2)**:
   - All generated test reports covering Unit Testing, System Validation, Code Coverage, and Branch Coverage are archived in the root [`../docs/`](file:///docs/) directory.
